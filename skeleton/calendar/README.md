# Calendar & To-Dos

Stand: {{DATE}}. The Atlas-First calendar and task hub for {{USER_NAME}}. Everything with a date or time window lives in
`## Timeline` below (or as `due:` in the frontmatter of a contract/person/project page, which `atlas.py calendar` merges
automatically). Undated tasks live in `## Open To-Dos` until scheduled for a specific day.

Format in `## Timeline`:
- `- [ ] YYYY-MM-DD [kind] What` (or date range `YYYY-MM-DD..YYYY-MM-DD`, or `yearly MM-DD`, plus optional `HH:MM` or `HH:MM-HH:MM`)
- Status: `[ ]` open/planned, `[x]` done, `[-]` skipped/cancelled
- Kinds: `[event]`, `[blocked]`, `[goal]`, `[goal:A]`, `[workout:cycling]`, `[workout:running]`, `[todo]`, `[birthday]`, `[deadline]`
