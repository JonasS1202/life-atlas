# Journal

Everything with a date: conversations, events, decisions, findings, thoughts worth keeping as they were.
`journal/<year>/<YYYY-MM-DD>_<topic>.md` (template: `_atlas/templates/journal.md`).

The journal is the evidence; the areas hold the current state. When a journal entry changes a fact (a new insurance
premium, a decision about the car), update the area page in the same turn and link the entry from it.
