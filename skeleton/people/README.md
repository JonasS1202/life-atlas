# People

One page per person: `people/<first-last>.md` (template: `_atlas/templates/person.md`). Name in the first heading
(the search hook uses it), `aliases:` in the frontmatter for nicknames. What the person is to the user, how to reach
them, what matters (birthdays as `due:`), history in dated lines. Contact data the user gave is fine here; passwords are
not.
