# Tags

Stand: {{DATE}}. Every page carries `tags:` from this list (lowercase, singular, in {{LANGUAGE}}). New tags are added
**here first**, with meaning and synonyms; then they may be used. Synonyms are what the user might say instead: the
search hook maps them to the tag, and `atlas.py check --fix` replaces them on pages. One row per tag; the tag in **bold**.

| Tag | Meaning | Synonyms |
|---|---|---|
| **atlas** | About Atlas itself | |
| **log** | Daily log written by the stop hook | |
| **learned** | Rule or skill adopted from an agent's own learning (e.g. Antigravity /learn) | |
| **self** | About the user themself (profile, values, goals, patterns) | ich, selbst |
| **person** | A person in the user's life | contact, kontakt |
| **contract** | A contract, policy, subscription | vertrag, abo, police |
| **deadline** | Something with a date that matters | frist, termin |
| **calendar** | Calendar timeline, events, blocked dates, workouts, goals and to-dos | kalender, todo, aufgabe, event, workout |
| **sport** | Sport, endurance training, coaching, workouts, physiology | training, laufen, running, triathlon, athletik |
| **project** | An undertaking with an end, a code repository | projekt, repo |
| **preference** | How the user wants things done | vorliebe, wunsch |
